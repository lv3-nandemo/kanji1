# かんじドリル 1ねん

小学1年生で習う漢字80字を、スマートフォンで手書き練習できるドリルです。

- 書き順アニメーション・1画ずつの図・書き順チェック
- よむ / えらぶ / かく の3つのクイズ
- サーバー不要(このフォルダの `index.html` 1つで動きます)
- 練習の記録は、使っている端末のブラウザの中だけに保存されます
